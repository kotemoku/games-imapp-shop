# public/img/cards/ — 札の関連画像の置き場

札に画像を付ける手順（表示側は実装済み。ファイルを置いて札に書くだけ）：

## 1. 画像を用意する
- **webp形式・幅1200px以下・1枚150KB目安**（変換は言ってくれれば一括でやります）
- ファイル名は `札のuid_連番.webp`（例：`kameoka_1577_1.webp`＝亀山城の1枚目）

## 2. このフォルダに置く

## 3. data/cards.seed.json の該当札に書く
```json
"deep": {
  "ja": {
    "body": "…",
    "images": ["img/cards/kameoka_1577_1.webp"],
    "imageCredit": "写真：亀岡市提供",
    ...
```
- `images` は複数可。ja/en 両方に同じ配列を書く（クレジットは言語ごとに）
- **`imageCredit` は必須運用**。書式の例：
  - 市町提供：`写真：亀岡市提供` ／ `写真：南丹市観光交流室提供`
  - Wikimedia Commons：`写真：〇〇（Wikimedia Commons, CC BY-SA 4.0）`
  - 国交省等：`出典：国土交通省近畿地方整備局ウェブサイト`
  - 自分で撮影：`写真：teraia` （表記省略も可だが統一のため推奨）

## 4. デプロイ
`npm run deploy`

## 権利まわりの決まり（§7）
- **許可の記録を残す**：市町からの許可メールは docs/permissions/ に保存（フォルダ作成済み）
- CCライセンスはライセンス名まで表記（BY-SA なら改変時も同条件）
- 「フリー素材」でも**再配布・商用可・クレジット条件**を1枚ずつ確認してから使う
- 人物がはっきり写る写真・私有地内の写真は使わない

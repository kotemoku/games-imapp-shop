# 通達: 「ダサい」は一番ダメ — 見た目品質の共通基準（全タイトル共通・必読）

> **送付先**: 全ゲーム開発担当（既存・新規を問わず）
> **送付元**: imapp チーム
> **日付**: 2026-07-19
> **重要度**: 高（恒久ルール。EMBED-CONTRACT と同格で全タイトルに適用）

## 0. 方針

**機能が動いていても、見た目がダサければ出荷しない。**
プレイヤーとお店の人の目に触れるすべての面——ホーム画面アイコン・LP・ゲーム内 UI・
フォント組版・キャラ画像——は「ダサくないか」を出荷基準に含める。
お店の看板を借りて商売をするゲーム群である以上、見た目の雑さはお店の恥になる。

## 1. ホーム画面アイコン（発覚事例: aozora-hanten 2026-07-19）

「ホーム画面に追加」で初めて露呈する事故が 2 系統ある。**全タイトル必須対応**:

- [ ] **`manifest.webmanifest` を置く**（name / short_name / `display: "standalone"` /
      `theme_color` / `background_color` / icons 192+512、`purpose: "maskable"` を含む）。
      無いと Android で「ただのブックマーク」になり favicon が白丸に浮く。
- [ ] **`apple-touch-icon`（180px）は不透明・フルブリード**。
      透過や角丸を含む PNG は **iOS で余白が黒く塗られて潰れる**。角丸は OS に任せる。
- [ ] **maskable 対応**: 主役モチーフはアイコン中央 80% の安全圏に収める
      （Android は端末により円・角丸・スクワークルで切り抜かれる）。
- [ ] favicon（64px 程度）も用意。タブ・ブックマークの顔。
- [ ] **実機で確認してから出荷**: iOS Safari 共有→ホーム画面に追加／
      Android Chrome メニュー→アプリをインストール。

## 2. 日本語組版

- [ ] **見出しの泣き別れ禁止**（「〜推し / を、」のような折返しは恥）。
      見出しは文節単位のスパン（`display:inline-block`）で改行許可点を明示する。
- [ ] 本文の日本語折返しは文字単位の折返し（Phaser なら `useAdvancedWrap: true` 等）を
      明示する。日本語はスペース区切りでないため既定の wrap では溢れる。

## 3. 画像アセット

- [ ] 生成画像（ChatGPT 等）の**白背景・偽透過チェッカー柄は「焼き込まれている」前提**で
      扱い、透過処理（外周連結の無彩色除去）をしてから使う。実装例は
      aozora-hanten リポジトリの透過スクリプト参照。
- [ ] **同名ファイル差し替えはキャッシュで古い絵が出続ける**。差し替わる素材は
      内容ハッシュ名にするか、`?v=N` のバージョン付き URL で読み込む
      （配信規約 README「配信規約」と同趣旨）。
- [ ] キャラ画像は**四角のカード枠**で全身を見せる。丸トリミングで頭や足を潰さない。

## 4. 出荷前チェック（最低ライン）

- [ ] スマホ実寸（375〜430px 幅）のスクリーンショットで全画面を目視
- [ ] リンク切れ・読み込み失敗・console エラー ゼロ
- [ ] 文字の重なり・はみ出し・泣き別れ ゼロ
